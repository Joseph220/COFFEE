# COFFEE

A simple static website for a coffee shop landing page. This repository contains the HTML and CSS used to build the site layout, hero section, about section, and specials cards.

## Features

- Responsive layout with media queries
- Pinned header with anchor navigation
- Special offers section with product cards
- Mobile-friendly images and typography

## Tech

- HTML5
- CSS (no JS required for the basic site)

## Getting started

1. Clone the repo:

```
git clone https://github.com/Joseph220/COFFEE.git
cd COFFEE
```

2. Open the site in your browser by double-clicking `index.html`, or serve it locally:

# COFFEE
# Python 3

python -m http.server 8000
