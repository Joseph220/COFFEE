# COFFEE

A simple static website for a coffee shop landing page. This repository contains the HTML and CSS used to build the site layout, hero section, about section, and specials cards.

## Features

- Responsive layout with media queries
- Pinned header with anchor navigation
- Special offers section with product cards
- Mobile-friendly images and typography

## Tech

- HTML5
- CSS (no JS required for the basic site)

## Getting started

1. Clone the repo:

```
git clone https://github.com/Joseph220/COFFEE.git
cd COFFEE
```

2. Open the site in your browser by double-clicking `index.html`, or serve it locally:

```
# Python 3
python -m http.server 8000
# then open http://localhost:8000 in your browser
```

## Project structure

- `index.html` — main markup
- `style.css` — styles and responsive rules
- image assets used by the site (logo, coffee images, backgrounds)

## Customization

Update the content in `index.html` and the styles in `style.css` to change the copy, images, or layout. For production, consider optimizing images and adding build tooling.

## Deployment

To deploy this static site, you can host the files on GitHub Pages, Netlify, or any static-file host. A simple GitHub Pages deployment:

1. Push the repo to GitHub.
2. In repository settings, enable GitHub Pages from the `main` branch (or create a `gh-pages` branch).

Alternative: drag the site folder into Netlify for instant hosting, or use any static hosting provider.
